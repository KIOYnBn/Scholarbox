
## 笔记附件 attachments/（第十六轮反馈）

用户指出笔记引用图片没有专门文件夹。实现：
- 新增 attachments.ts：ATTACHMENTS_DIR='attachments'、sanitizeImageName（路径/非法字符）、
  uniqueImageName（撞名 -2/-3，无扩展名按 .png）、saveNoteImage（mkdir+写盘）、
  pickImageFiles（动态 input）；
- asset-url.resolveNoteImagePath：attachments/ 前缀直通 + decodeURIComponent 一次——
  修复 marked 编码中文文件名后 convertFileSrc 二次编码（%E6→%25E6）导致的阅读模式 404；
- MarkdownEditor：onImageFiles prop + 根 div onPasteCapture/onDropCapture（只拦文件、
  文本粘贴不拦），NoteSurface handleImageFiles 统一走保存+insertBlock，工具栏加
  ImagePlus 按钮；
- 三种入口：工具栏选文件 / Ctrl+V 粘贴截图 / 拖拽图片文件。git commitAll 全库枚举，
  attachments/ 自动同步。
- 5 条新测试（attachments.test.ts），394 全绿。实测：选文件与连续粘贴两次 →
  attachments/ 落盘 + 撞名序号正确；两种模式渲染 OK。
- 环境坑：本次会话 bash 退出会杀掉 scholarbox 子进程——测试脚本必须与启动同一条命令；
  CodeMirror 虚拟化导致 textContent 断言不可靠，用磁盘与 img.naturalWidth 验证。

## 大纲阅读模式跳转修复（第十七轮反馈）

用户报告阅读模式点大纲无法跳转。根因：大纲面板点击走编辑器句柄 revealLine，
阅读模式下编辑器 display:none 且用户看的是渲染 HTML——滚了也看不见。
修复：
- outline.ts 加 applyOutlineAnchors(root, markdown)：按出现顺序给渲染出的
  h1-h6 打 data-outline-line（跳过 .md-embed 里的标题——来自别的笔记）；
- ReadingView effect 渲染后调用（依赖加 markdown）；
- NoteSurface 加 jumpRef prop + readWrapRef：模式感知跳转——read 查
  [data-outline-line] scrollIntoView smooth，其余走 editorRef.revealLine；
- FullNoteView 加 jumpA/jumpB ref 贯通 NotePane → NoteSurface / NoteDrawer，
  抽屉大纲点击改走 jump.current（NoteDrawer 删掉不再用的 handle prop）。
实测：锚点 5 个、点「深处的标题」scrollTop 0→874 元素入视口。
环境坑：bash 退出杀 scholarbox 子进程 → 启动与测试必须同一命令；
临时 padding 测试时 app 若开着可能用内存态覆写笔记文件，测完立即核对。

  再粘贴取消 → 不落盘。测试痕迹已清。
- 注意：用户已在自己使用 app（新增 biology 仓库、笔记「植物系统分类学」、
  attachments/ 已有 APG-IV.png 等）——测试脚本要动态适配当前库/笔记名，
  清理时只删自己的测试文件，别动用户数据。

## Mermaid 图表支持（第二十轮需求）

- npm 安装 mermaid v12.3（动态 import 按需加载，mermaid.ts 自声明最小结构类型
  ——包的 default export 类型与 TS namespace 解析不兼容）；
- 阅读模式：mermaid.ts applyMermaid(root)——`pre > code.language-mermaid` 替换成
  .md-mermaid 容器 + mermaid.render（缓存按源码 key，上限 60），语法错误保留源码
  加 error 样式；ReadingView effect + embed.ts applyEmbeds(wrap) 都接入；
- 实时预览：computeBlockDecorations 围栏循环识别 ```mermaid 语言（去掉首尾围栏行
  取图源），MermaidWidget（peekMermaidSvg 同步首帧避免闪烁，异步补渲染），
  光标进块露源码（touchesActive 既有机制），忽略折叠范围；
- CSS：.md-mermaid/.cm-md-mermaid 居中容器 + svg max-width。
- 测试坑：测试脚本 safeEval 丢 arg 参数导致 clickAria 全部失效（返回 false）——
  症状是「模式切不过去」，与功能无关。
- 399 测试全绿，安装包重打（00:01，7.13MiB——mermaid chunk 使包体 +1.2MiB）。
  实测两种模式流程图渲染正常（截图）。
