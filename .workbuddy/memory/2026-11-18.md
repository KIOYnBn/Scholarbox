# 2026-11-18

## 笔记系统改版（用户四条不满）

### 1. 笔记底色可选
- `EditorPrefs.noteBackground`：theme / paper / sepia / mint / slate / ink。
- 实现方式不是铺 background-color，而是在笔记容器上**覆盖 `--sb-*` 变量**（`lib/notes/appearance.ts`
  的 `noteSurfaceStyle`），代码块、引用、表格、行内代码会一起变，不会出现白底代码块压在米黄纸上。
- 应用点：FullNoteView 根、NotesPane 根、NoteSurface 根。

### 2. 「左右空白极大」的真正原因
不是容器居中，而是 `styles/index.css` 里 `.cm-host .cm-content { max-width: 76ch }` ——
正文被钉在 ~620px 且**左对齐**，容器 992px，右边全空。改成 `max-width: 100%`，
宽度交给新设置 `noteWidth`（窄 40rem / 中 48rem / 宽 62rem / 满宽，默认宽）。
同时 `FullNoteView` 的 `max-w-4xl` 去掉。
顺带把「列宽标尺」（76ch 竖线）删了，缩进参考线改成只在当前行画（以前整篇铺竖虚线，很脏）。

### 3. 字号可以用鼠标拖
新增 `components/notes/FontSizeControl.tsx`：工具栏「Aa」浮层，含 range 滑杆（11–28px，
拖动即时生效）+ A−/重置/A+，同浮层里还有底色色块与版心宽度。范围常量在 appearance.ts。
**注意**：浮层的父行不能加 `overflow-hidden`，否则弹层被裁掉（踩过）。

### 4. 实时预览对齐 Obsidian
- 模式三态：阅读（只读）/ 源码 / 实时预览，按钮带文字标签；右栏窄容器传 `compact`，只留图标。
- `markdown-syntax.ts` 重写：
  - **列表**：`- ` / `1. ` 的标记从「整段隐藏」改为「保留缩进、只藏标记」，并带出
    `list: { ordered, marker }`；`MarkdownEditor` 用 `ListWidget` 渲染成圆点/序号 ——
    这正是「1. 2. 3. 看不到」的根因。
  - **行内标记**：`**`、`~~`、反引号、`[..](..)`、`![..](..)` 的标记也进 hidden（以前只套样式不藏标记）。
  - 修掉行首斜体偏移一格的 bug；新增 `dedupeRanges()` 避免嵌套标记产生重叠 replace 区间（CM 会抛错）。
- 任务框仍换成勾选框。

### 其他
- `EditorPrefs` 新增字段时，zustand 持久化默认浅合并会把整个 `editor` 覆盖成旧对象。补了 `merge` 深合并。
- 删掉三个没实现的开关（实时预览 / 嵌入预览 / 列宽标尺）——「拨了没反应」比没有更糟。
- 设置面板重排：底色 / 版心宽度 / 字号 放最上面。
- 测试：`markdown-syntax.test.ts` 新增 6 条（有序列表序号、缩进保留、行内标记隐藏、行首斜体、重叠去重），
  全量 337 条通过。

## 阅读 PDF 时的三栏折叠（用户第二轮需求）

折叠逻辑本来就有（`Ctrl+B` / `Ctrl+Alt+B`，右栏收起时浮一个「笔记」按钮），
但**桌面上没有任何可点的入口**：`SidebarHeader` 的收起按钮写着 `hidden max-lg:inline-flex`
（只在平板宽显示），`ReaderPane` 的两个开关也是 `lg:hidden`。于是左栏一旦收起，
鼠标用户就再也点不回来，只能猜快捷键。

改动：
- `SidebarHeader`：收起按钮改成所有宽度都显示，用 `PanelLeftClose`。
- `NotesPane` 头部：加 `PanelRightClose`「收起笔记栏 · Ctrl+Alt+B」。
- `ReaderPane` 头部：两个 `lg:hidden` 开关改成常显 + `active={open}`，标题随状态变
  （收起/展开目录栏 · Ctrl+B）。
- `AppShell`：左栏收起时左侧浮出「目录」按钮（镜像右侧的「笔记」），点回来。
- README「三栏折叠」表格补上四个可点入口。
- 实测（CDP）：两栏都收起后 PDF 占满、两个浮动按钮就位；两栏各自 3 个入口 aria-label 都在。

现状复查：整条链路（Shift+X → 框选 → `capturePageRegion` 2 倍重渲染 → 写 `assets/`

- 实时预览把图片语法整行藏掉，只剩一个裸的 alt 文字。

改动：
- `ReaderPane` 标题栏加相机按钮（「截图插入笔记 · Shift+X」，active 跟随 captureMode）；
  `NotesPane` 标题栏也加一个，派发 `scholarbox:capture` 让原有的监听活过来。
- 新增 `src/lib/editor/block-insert.ts`（纯函数 + 8 条单测）：行内插入前后补空行、

- 顺带修掉一处我自己在 QA 时误点「链接」按钮污染用户 note.md 的 `[链接文字]()`。

## 笔记编辑四项修复（第四轮需求）

用户报了四个问题：模式切换字号跳变、不支持 $/$$ LaTeX、实时预览里代码块/HTML 显示源码、
多级列表不支持且只有首行缩进。

- **字号跳变**：根因是切模式时 `options` compartment 被整体重配成 editable/readOnly，
  主题（字号/字体/换行）一起被清掉。拆出独立的 `readonly` compartment，初始装配时就装好主题。
- **LaTeX**：新增 `src/lib/notes/math.ts`（scanMath/maskMath/renderMathHtml + katex 依赖 +
  katex.min.css）。规则对齐 Obsidian：`$` 后不能紧跟空格、行内代码/围栏内的 `$` 不算、
  渲染失败回显原文。阅读模式在 `reading.ts` 里先 mask 公式再转义 HTML 再过 marked，
  restore 时塞回 KaTeX HTML。10 条单测。
- **实时预览渲染代码块/HTML/公式**：关键坑——**跨行 replace 装饰不允许从 ViewPlugin 出**，
  放 plugin 里整片装饰静默失效（第一版就是这么翻车的，实测全部 widget = 0）。
  代码围栏整块 + 块级 $$…$$ 移到 StateField（`blockDecorationsField`，配置经
  `setBlockConfig` effect 注入，选区/文档变化重算）；行内公式、单行 HTML、列表标记、
  图片留在 plugin。BlockWidget 挂 `md-body` 类复用阅读视图样式。
- **多级列表悬挂缩进**：`markdown-syntax` 现在记录 `indent` 并把缩进空格一起 `hidden`，
  plugin 给列表/任务行挂行级 decoration（padding-left = indent+2ch, text-indent: -2ch），
  嵌套圆点跟着缩进、折行文字与首行对齐。阅读模式补了 ul ul → circle/square 的样式。

测试环境注意：app 按 `lastOpenedAt` 打开最近仓库，实测时打开成了「毕业论文」仓库，
靠改 `%APPDATA%/app.scholarbox.desktop/vaults.json` 的 activeId 切回 E:/markdown/app。
测试笔记（zz-preview-test.md）已删，文献 note.md 已恢复，registry activeId 已确认归位。

最终实测：三种模式字号均 23px 一致；实时预览行内公式×1、块级公式、代码块、
details、红段落、8 个列表标记、8 行悬挂缩进全部渲染；阅读模式同样全渲染。
355 条测试全绿，安装包重打（21:48）。

## 块级 widget 字号修复（用户跟进反馈）

代码块 / HTML 嵌入内容在实时预览里比正文小：BlockWidget 挂 `md-body` 复用样式，
而 `.md-body` 钉死 14.5px，`.md-body pre` 再 0.82em、`code` 再 0.86em（嵌套双重缩小，
23px 正文的代码块只有 16.2px）。修复：`.cm-host .cm-md-block.md-body { font-size:1em;
font-family:inherit }`，`pre`/`code` 也归一成 1em。实测 body/code/html 段落全部 23px；
KaTeX 是 1.21em（27.8px）——KaTeX 官方排版比例，阅读模式同比例，保留。

坑：每次启动 app 都会把「最近打开」（lastOpenedAt 最大）的仓库写进 activeId，
实测前后都要检查 `%APPDATA%/app.scholarbox.desktop/vaults.json` 并切回 E:/markdown/app。

## 标题折叠收不掉公式块（第五轮反馈）

用户贴了一段含独立 `=` 行的 ARI 公式，反馈「收起标题内容时无法收起」。

排查（两轮诊断构建 + console 日志）：折叠 effect 正常派发、块 widget 也重算了，
但 markdown 自带 foldService 给出的折叠区间只有 11 个字符（97→108）——
**公式里单独一行的 `=` 被 Markdown 解析成 setext 标题**（段落 + 下一行 `=` = 一级标题），
标题的 section 在公式块中间被截断，公式（110→574）不在折叠范围内，
且折叠范围与公式不重叠 → overlapsFold 不触发 → 块 widget 留在外面。

两层修复：
1. `headingFoldService`（Prec.high 的 foldService）：标题折叠按行扫描找下一个
   同级/更高级标题，不依赖语法树，公式/代码不再干扰折叠范围；
2. `blockDecorationsField` 感知 foldEffect/unfoldEffect（折叠/展开后重算），
   overlapsFold 命中的块级 widget（公式/代码块）跳过渲染，让位给折叠占位符。

实测：折叠「有公式的小节」后 math widget 1→0（公式消失），展开 0→1 恢复。
公式本身渲染没问题（KaTeX 支持 \binom/\displaystyle/\left[ 等），不需要重写。
