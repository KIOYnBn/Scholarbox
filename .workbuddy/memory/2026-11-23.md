## 笔记系统对齐 Obsidian 第三批（第十一轮需求）

新增六个 Obsidian 核心特性（模块：outline.ts / links.ts / callout.ts + reading.ts / markdown-syntax / NoteSurface / FullNoteView / useOpenWikiTarget / standalone store）：

1. `==高亮==`：reading.renderHighlights（跳过 frontmatter/代码）+ markdown-syntax highlight 规则 + mark CSS。
2. Callout：`> [!type]` 全类型归一 8 色系。阅读模式 applyCallouts DOM 后处理——
   坑：marked 把标题行+正文塞进同一个 <p>（内含 \n），`(.*)$` 匹配不到多行，
   parseCalloutMarker 只取首行 + applyCallouts 把剩余行还原成正文段落。
   实时预览行级 Decoration.line 着色 + [!type] 标记隐藏（cm-md-taken）。
3. 大纲面板：extractOutline（跳 frontmatter/围栏）+ NoteDrawer 抽屉组件 +
   MarkdownEditorHandle.revealLine（dispatch selection+scrollIntoView）。
   NoteSurface 加 handleRef 透传（useEffect 每渲染同步 editorRef）+ onValueChange 回传。
4. 反向链接面板：links.ts（NoteDoc/findBacklinks/匹配规则对齐 useOpenWikiTarget：
   路径/纯名字/文献夹名/大小写不敏感，跳围栏跳自己，按行聚合）。
5. 未解析链接点击创建：useOpenWikiTarget 兜底 create 同名独立笔记。
6. Ctrl+E 编辑/阅读切换（NoteSurface keydown）。
7. 重命名联动：updateLinksAfterRename 扫全库改写引用（保持写法形态与别名），
   standalone.rename 调用后 load 刷新文献库缓存。

测试环境坑：CDP 连到的是旧实例（端口占用时新实例起不来），实测前必须 kill 干净。
另外「打开阅读」进的是三栏，全屏笔记要从右栏「独立打开笔记」进入（大纲/反链按钮在那）。

## 文献笔记唯一文件名 noteName（第十二轮反馈）

用户指出文献笔记全叫 note.md 对双链不利。实现：
- schema 加 `noteName`（normalizeMeta/serializeMeta 均带）；
- repository：noteFileOf() 助手；list() 先跑 migrateNoteNames()（note.md → <标题>.md，
  幂等，老路径写法链接由 updateLinksAfterRename 改写）；create 用标题命名；
  saveNote/readNote 走 readMetaLite；saveMeta 检测标题变化 → 文件改名 +
  全库引用联动（updateLinksAfterRename 扫每个文献目录下全部 .md——原来只扫
  note.md 的写法在迁移后失效，已改）；
- item.ts 加 paperNoteFile(paper)；useOpenWikiTarget 的文献笔记匹配放宽为
  papers/<dir>/<任意>.md；FullNoteView 反链 docs 用 paperNoteFile；
- 测试坑：MemoryVaultFS 建目录后才有文件（目录不存在直接 FsError）；反链路径
  形式不带 .md 后缀（与 Obsidian 一致）。
